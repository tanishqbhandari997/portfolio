# Tanishq Bhandari's portfolio

This folder is a self-contained portfolio bundle. Keep the files together when
sharing it; the project pages use shared navigation and demo support scripts.

## Open the portfolio

Open `index.html` in a browser and choose a project. Every project includes a
“Back to portfolio” link.

## Web projects

- **Ashapura Enterprises** — HELLO GOLD distributor website.
- **Pocketwise** — personal finance dashboard with budgets and CSV import.
- **Campusly** — student and faculty college portal demo.
- **Gather** — browser-local chat with same-browser tab sync.
- **Fieldnotes** — illustrative Karnataka crop-yield dashboard.
- **Pathfinder** — transparent educational readiness estimator.
- **Stockroom** — sample inventory and billing workspace.
- **Matchwork** — in-browser PDF resume and job-keyword comparison.
- **Wayfinder** — travel dashboard using public APIs.
- **Fieldnotes Journal** — browser-local Markdown writing studio.
- **Supplyline** — suppliers, batch inventory, and reorder planner.

The portfolio and its sample data work without a backend or account. Interactive
demos that offer a profile selector use demo profiles only; this is not
authentication or access control. Data is saved in this browser's local storage.
Do not enter real banking, student, or confidential data. Wayfinder and Matchwork
load public services/libraries and need an internet connection.

## Desktop project

`system-monitor.py` is an optional Python desktop utility for monitoring CPU,
memory, disk, and supported temperature sensors. Install its dependency with
`python -m pip install -r monitor-requirements.txt`, then run
`python system-monitor.py`.
